# Анализ продаж кофейни ☕

Исследование транзакционных данных сети кофеен для определения профиля типичного клиента, выявления наиболее и наименее продаваемых продуктов, а также оценки эффективности торговых точек. Проект включает полный цикл обработки данных: от распаковки JSON-объектов до статистического анализа и визуализации с практическими рекомендациями для бизнеса.

---

## 📋 Описание проекта

### Бизнес-цель заказчика: 
- Основываясь на полученных данных о трех других точках продаж, понять, где открыть новую точку продаж, на какие продукты сделать ставку в продажах, на какую аудиторию ориентироваться в маркетинговых компниях. 
  
### Цели анализа данных 
- Определить портрет типичного клиента сети кофеен
- Выявить факторы, влияющие на продажи
- Определить наиболее эффективную точку продаж
- Определить продукты-драйверы
- Сформировать практические рекомендации для увеличения выручки и оптимизации ассортимента.

### Задачи, которые решает проект
- **Очистка и предобработка данных**: распаковка вложенных JSON-структур, удаление дубликатов, создание новых признаков (возраст, возрастные группы, общая сумма чека)
- **Исследовательский анализ данных (EDA)**: изучение распределений, выявление выбросов, анализ связей между переменными
- **Статистический анализ**: проверка гипотез о влиянии возраста и пола на сумму покупки, анализ зависимости выбора категорий товаров от города
- **Продуктовый анализ**: ранжирование продуктов по популярности, выделение лидеров и аутсайдеров продаж
- **Анализ торговых точек**: сравнение эффективности разных точек продаж, выявление наиболее успешной локации
- **Формирование рекомендаций**: подготовка конкретных предложений по оптимизации бизнес-процессов

### Основные этапы работы

1. **Обзор и описание данных**
   - Загрузка датасета с Google Drive
   - Первичный анализ структуры данных
   - Выявление проблем (вложенные JSON-объекты, дубликаты, пропуски)

2. **Очистка и предобработка**
   - Удаление дубликатов (57 записей)
   - Распаковка JSON-полей (product_info, store_info, customer_info)
   - Создание новых признаков (age, age_group, total)
   - Стандартизация данных (унификация названий городов)

3. **Разведочный и статистический анализ**
   - Анализ целевой переменной (total)
   - Исследование возрастных групп посетителей
   - Анализ влияния пола на total
   - Продуктовый анализ — выявление лидеров продаж
   - Сравнение эффективности торговых точек
   - Статистические тесты (Шапиро-Уилка, Манна-Уитни, Хи-квадрат)

4. **Визуализация результатов**
   - Боксплоты для выявления выбросов
   - Гистограммы распределений
   - PairGrid для анализа взаимосвязей
   - Корреляционная матрица
   - Круговые диаграммы и тепловые карты

5. **Формирование выводов и рекомендаций**
   - Обобщение результатов анализа
   - Подготовка практических рекомендаций для бизнеса

## 📊 Основные результаты

### Профиль типичного клиента:
- **Пол:** преимущественно женщины
- **Возраст:** 24-44 года
- **Любимый продукт:** Latte
- **Средний чек:** ≈300 рублей

### Ключевые инсайты:
- Возраст и пол клиентов **не влияют** на сумму покупки
- Наиболее продаваемая категория — **Coffee**
- Самая успешная торговая точка — **ID 5 (Москва)**
- Выявлена статистическая связь между выбором категории товаров и городом

### Рекомендации бизнесу:
- Сфокусировать маркетинг на женщинах 24-44 лет
- Сделать Latte "фирменным" продуктом с сезонными предложениями
- Исключить из ассортимента неэффективные продукты (Espresso Roast, Chili Mayan и др.)
- При открытии новых точек ориентироваться на опыт московской локации ID 5
